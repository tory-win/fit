# 입핏 개인정보 처리방침 (초안 v0.2)

- 작성일: 2026-07-26
- 상태: **법무 검토 전 초안.** 스토어 제출 전에 변호사 검토와 공개 URL 확보가 필요하다.
- 근거: 현재 구현(`app/src`) 기준으로 실제로 저장·전송하는 것만 적는다. 하지 않는 일은 적지 않는다.

---

## 1. 한 줄 요약

입핏은 **계정을 만들지 않고**, 사진과 프로필 및 완성된 입어보기 결과를 **이용자 기기 안에** 저장한다. 서버로 나가는 것은 두 가지뿐이다 — 날씨 조회(위치 정보 없이 서울 고정 좌표)와, 이용자가 직접 요청한 **AI 착장 미리보기 생성**이다.

## 2. 수집·저장하는 항목

| 항목 | 저장 위치 | 필수 여부 |
|---|---|---|
| 생년월일, 태어난 시간, 부르는 이름 | 기기 내부 저장소 | 생년월일만 필수 |
| 키·몸무게·평소 사이즈·선호 핏·체형 질문 답변 | 기기 내부 저장소 | 전부 선택 |
| 옷 사진 | 기기 내부 파일 영역 | 선택(앱 사용에는 필요) |
| 코디 확정 기록, 만족도 피드백 | 기기 내부 저장소 | 자동 기록 |
| 전신 사진 1장 | 기기 내부 파일 영역 | 선택 · 별도 동의 4항목 |
| AI 착장 미리보기 이미지 | 기기 내부 파일 영역 | 이용자가 지울 때까지 보관 |
| 알림 시간·스타일패스 상태 | 기기 내부 저장소 | 선택 |
| 오류 기록(화면 이름·오류 메시지·앱 버전·기기 종류) | 기기 내부 저장소 | **기본 꺼짐**, 이용자가 켤 때만 |

**저장하지 않는 것**: 이메일·전화번호·주소·결제 정보·연락처·위치 좌표·사진의 촬영 위치(EXIF·GPS는 저장 전에 제거한다).

## 3. 사진 처리 방식

- 촬영·선택한 사진은 저장 전에 캔버스로 다시 인코딩한다. 이 과정에서 **EXIF 전체(촬영 위치·기기 정보·방향 태그)가 제거**된다.
- 원본 파일은 저장하지 않는다. 긴 변 1600px, JPEG 품질 82로 변환한 결과만 남는다.
- 옷 사진은 평소 기기에만 보관한다. AI 입어보기를 실행하면 이용자가 그 결과에 사용하기로 고른 옷 사진만 생성 서버로 전송한다.

## 4. 제3자 전송

| 대상 | 전송하는 것 | 시점 | 근거 |
|---|---|---|---|
| Open-Meteo (날씨) | 서울 고정 좌표(37.5665, 126.978), 날짜 | 앱 실행 시 | 이용자 위치를 수집하지 않으며 개인 식별 정보가 없다 |
| 이미지 생성 API | 전신 사진 1장 + 해당 코디 또는 상품의 옷 사진 | 이용자가 입어보기를 요청하고 **광고 완료 또는 쿠팡 진입이 확인된 뒤 AI가 시작될 때만** | 사전 동의 4항목 |

- 전신 사진은 등록만 해두면 기기를 떠나지 않는다. 미리보기를 열지 않으면 전송도 없다.
- 생성이 끝나면 전송한 사진은 즉시 폐기하며, 결과 이미지만 기기로 돌아온다.
- **국외 이전**: 이미지 생성 API는 국외 사업자다. 정식 출시 전에 이전받는 자·국가·이전 항목·보유 기간을 이 문서에 확정해 적고 별도 동의를 받는다. (**미확정 — 프로덕션 공급자 계약 전**)

## 5. 보유·파기

| 데이터 | 보유 기간 |
|---|---|
| 옷 사진·프로필·코디 기록 | 이용자가 지울 때까지 (기기 안) |
| 휴지통의 옷 | 7일 후 자동 완전 삭제 |
| AI 착장 이미지 | 이용자가 결과별로 지우거나 내 데이터 전체 삭제를 실행할 때까지 |
| 오류 기록 | 최근 30건, 이용자가 지우면 즉시 삭제 |

- 마이 → 내 데이터 → **내 데이터 전체 삭제**로 위 전부를 즉시 지울 수 있다.
- **내 사진 삭제**는 전신 사진과 동의 기록만 지운다. 이미 만든 입어보기 결과는 스타일북에 남으며 결과별로 따로 지울 수 있다.
- 앱을 삭제하면 기기 안 데이터도 함께 사라진다. (그래서 백업 파일 만들기를 제공한다)

## 6. 이용자의 권리

- 열람: 마이 → 내 데이터에서 저장된 항목과 수량을 확인할 수 있다.
- 정정: 사주 프로필·체형은 언제든 수정할 수 있다.
- 삭제: 항목별 삭제와 전체 삭제를 모두 제공한다. 계정이 없어 별도 탈퇴 절차는 없다.
- 이동: 백업 파일(zip)로 옷장·프로필·코디 기록을 내보내 다른 기기에서 가져올 수 있다. 전신 사진은 명시적으로 켤 때만 담기며, 입어보기 결과 이미지는 현재 백업 파일에 포함되지 않는다.

## 8. 광고·커머스

현재 보상형 광고 SDK와 쿠팡 파트너스 링크가 연결돼 있다. AI 입어보기는 보상형 광고 완료 또는 쿠팡 파트너스 진입이 확인된 뒤에만 시작한다. 광고 SDK의 실제 수집 항목·처리 사업자·보유 기간은 정식 출시 전 계약 내용과 법무 검토를 거쳐 이 문서에 확정한다.
